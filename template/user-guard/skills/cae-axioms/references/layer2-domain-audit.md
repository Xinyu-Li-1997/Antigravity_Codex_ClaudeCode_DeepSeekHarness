## 2A｜经验物理建模与外部确认分支

**显式注入的经验物理前提**（D1–D3，不依赖层 2M）：

- **D1**（物理规律平稳与守恒对称结构，接第一层五.3）：物理系统在给定适用尺度、受控外场及可比条件下服从特定时空对称群等变性，封闭系统服从基本守恒律（开放子系统服从带显式边界通量与源项的平衡律），且外部物理制约在跨时空同类条件下保持平稳。
- **D2**（多尺度不可逆粗粒化与闭合缺口条件）：宏观物理与工程系统的微观自由度不可穷举。在截断尺度 $\Lambda$ 内对微观自由度作多对一粗粒化会损失内部状态信息；当未解析自由度实质进入保留变量的演化关系时，截断后的控制关系即呈未封闭（若内力对消使保留变量自封闭，如孤立多体系统总质心与总动量，则不构成闭合缺口）。闭合关系系针对适用域 $\Lambda$ 确立的有效近似，超出 $\Lambda$ 后其物理依据不再成立。
- **D3**（跨语境归因稳定性与简约性，接第一层五.5）：引入跨独立实验辅助前提稳定性与简约性作为方法论前提，以在整体论归因下逐步收紧误差归因。

**由“第一层 + 层 1.5 + D1–D3（连续介质方向挂载层 2M）”导出的审查规范**：

1. **本体相容、根层优先截断与附加约束审查**（接一.2, 一.3, 一.4, 一.6, 一.8, 一.9 + 层 1.5 2A.1–2A.3, 三.3 + D1, D2 + 层 2M）

   - **构造本体全域固有矛盾与根层截断**（任意非空子域内均 $\Gamma \models \bot$，或在根层 `2A.1`、`2A.2` 及层 `2M` 第一级收支公理上存在共享不可满足核）：收缩适用域、调节参数、加密离散或消除下游分支的局部派生症状（如消除复特征值）均无法化解共享根冲突核，严禁以消症局部相容冒充根体系相容。唯一合法出路仅有更换构造本体以承载原宣称，或降格修改宣称或定义以如实匹配当前构造（按一.4 同一律回锁，修改后的新宣称不改变原宣称不可满足的既定事实）。
   - **越界误用导致的局部冲突**（在适用域 $\Lambda$ 内相容、超出 $\Lambda$ 失效）：按一.4 修改前提集将宣称严格收缩回 $\Lambda$ 内，或重构适用于新尺度的新本体，禁止靠局部调参掩盖越界失效。

   严格区分**可满足但语义未定**与**超定不可满足无解**两类状态：方程未封闭、欠定或逆问题多解均属可满足但语义未定，须在目的 G 下显式声明补充的闭合假设、选解准则、近似误差度量与适用边界 $\Lambda$，禁止暗藏于默认参数或隐式数值效应中。相反，超定无精确等式解（如 $x=0$ 与 $x=1$ 联立）在等式语义下已属 $\Gamma \models \bot$，补充选解准则不能使其原等式集相容；将其改写为残差最小化或容差满足属于按第一层 `一.4` 同一律回锁构造的新优化问题，须如实声明。

4. **校核与确认分离、条件化正向比对与归因可追溯**（接三.1–三.4 + 层 1.5 + D1, D3）
   检验求解器代码实现、收敛阶或与未经独立实验确证的程序互算，属于验证实现与数学规范一致性的**校核**（Verification），不能替代面向外部独立物理观测的**确认**（Validation）。用于标定闭合参数的观测子集不得重复充当该参数的独立确认。正向比对与逆向反演均含受 P3 约束的中介假设（正向比对亦可采用概率观测核；共享待检前提的中介在失配时仍可按三.4 联合归谬，但单独归因与正向确立另有条件）。仅当正向观测算子 $\mathcal{H}$ 近似单值、经独立标定且不共享待检假说核心前提时，将计算状态经 $\mathcal{H}$ 映射至未污染原始观测进行直接比对，才能规避非单射逆推的附加选解依赖与循环验证风险。在 D3 下，误差归因须沿输入、闭合、模型形式、离散与观测逐环可追溯，禁止在标定中将模型形式误差吸收进局部参数而切断追溯链。

5. **代理与降阶模型的良定义比较**（接一.5, 一.7 + 层 1.5 2A.4）

## 2C｜反身生态与代理生成系统分支

**显式注入前提与规范决策**（R1–R3）：

- **R1**（运行期策略反身生态与可证伪锁死假说，接 P2 + P4 + P5）：学术评价共同体与商业软件市场中存在结构性、非可忽略比例的评价与供给主体满足 P4 + P5，故审查不得默认系统非反身。在此基础上立出一条可证伪的跨时经验假说，须在观测前预先固定观察窗口 $\Delta t$、可独立指认的重大外生颠覆事件判据与实际淘汰标准。假设在时刻 $t_0$，一个依赖内部冲突旧底座的领域同时具备四项可观测结构条件。其一为多源误差互偿机制（`R1.1`），其二为外部容错与安全裕度掩护（`R1.2`），其三为高昂沉没切换与调参壁垒（`R1.3`），其四为买方或评价激励与公理证伪相隔离（`R1.4`，单一财政买方与优化现实效用而非底层自洽的多买方市场在此项上可同构）。则在观察窗口 $\Delta t$ 内、缺乏预先界定的重大外生颠覆事件（重大工程事故、买方或监管制度外生变更，或先于淘汰且独立公开出现的外部替代范式所迫使的生存危机）的情况下，该领域不会自发淘汰该冲突底座。
- **R2**（防反身权威归零决策规则，接一.6 + R1）：鉴于 R1 下外部权威代理极易沦为套利工具，在命题真伪、模型有效性与软件宣称的论证裁决中，主动将期刊名、引用数、头衔、估值、市占率与学科共识等**替代直接拆解的裸权威代理**论证权重归零，仅保留其文献定位与时间坐标功能（不排除经独立审计并作为显式桥接前提进入 $\Gamma$ 的计量溯源与标定可靠性陈述）。
- **R3**（训练期代理偏离生成系统，接 P2 + P5）：大语言模型等生成系统在训练与人类反馈对齐阶段以有损非充分代理（如语言流畅度、主流共识似然或人类偏好评分 $E$）替代实质外生真值目标 $T$，其推理期呈现的“顺从主流共识惯性”“迎合提问者倾向”与“产出貌似稳重的修辞端水”属待检经验偏置假设（静态训练代理失真对应第一层 `四.2`，区别于运行期动态策略博弈 `四.3`）。

**由“第一层（一.6, 四.1–四.4 + G）+ R1–R3”导出的审查与协作规范**：

1. **结构锁死与正当审慎的客观区分判据**（接 G, P2, 四.4 + R1）
   区分正当工程审慎与结构锁死，不作动机揣测，直接检验主体在目的 G 与非操纵硬反馈上的三项可观测取证行为：是否公开承认前提缺陷与适用边界；是否开放原始基准与未污染数据接受独立证伪；对替代构造是否仅设客观技术与可靠性门槛。同步锁定 `R1` 与后件否定严格对齐的**证伪条件**：若某领域在 $t_0$ 同时满足 `R1.1–R1.4`，却在预先固定的观察窗口 $\Delta t$ 内、无前述重大外生颠覆事件下经内部核查实际自发废止并淘汰该冲突底座，则 `R1` 锁死假说被证伪（开放原始数据与强基线否决构成充分可观测取证，不作为额外收窄证伪范围的附加门槛）。

2. **不可审计声明的证据态边界**（接 G, P2, 四.2, 四.3 + R1, R2）
   在反身生态中，处于不可审计闭源状态的声明在客观访问条件上使外部审查无法直接核查（不作主观动机揣测）。“未见公开反证或抄袭实锤”绝不逻辑等价于“已证独立原创或内部自洽”。核查此类对象须先标定其不可审计黑箱态，再从公开工程事实内部一致性与公开底层范式结构两路穿透核查（具体分层核查清单归入第三层）。

3. **代理生成系统协作的退出失真与回退条件**（接一.6, P2, 四.2, 四.4 + R3）
   依据第一层 `四.2`，共享同一表征映射 $r_S$ 的复核规则无法在混合 $r_S$-纤维内区分真例与假例（相关重复复核亦无必然降方差保证）；异源预训练家族交叉盲审属于待检经验辅助手段，可扩大检索覆盖面但受共享人类偏好代理偏置制约，不能单独替代形式退出条件。严格依据第一层 `四.4`，退出非反身代理失真须存在显式相容桥接前提集 $B$ 下的保守单向充分证书或使演化脱离非充分代理驱动（仅在须于同一混合纤维内保留真例同时排除假例时才必须引入不经 $r_S$ 因式分解的外部信息；保守拒收纯化纤维亦属合法分支）。退出动态反身回退须至少满足 `四.4` 三支之一（打破 P4 感知响应、建立相对 $B$ 的保守充分证书，或打破 P5 代理驱动）。在生成模型协作中的典型工程实现是：由人承担前提界定与责任，可计算产出锚定独立确定性外部执行器，非代码推演锚定独立反例、一手原文核对与定量反算。但须严守 `四.4` 断言边界：**仅当外部执行器或形式证明在显式相容桥接前提集 $B$（如规格与测试确已编码目标 $T$）下构成 $T$ 的保守充分证书，并叠加实际状态入域与放行见证时，才许可对 $T(x_{\mathrm{act}})$ 作正向断言**；人类担责、单次有限探针或盲测隔离本身仅能核查 $B$ 所编码性质或终止对抗回退，不自动消除静态失真，且人类审查者自身同样受 `P2` 与确认偏误制约。

# 中文计算物理与计算数学期刊体例

适用于面向国内计算物理、计算数学、力学与工程数值方法期刊的中文学术论文撰写与改稿。

## 一、篇幅与整体组织

1. **线性紧凑结构**：中文核心期刊普遍篇幅受控，推荐按“引言 → 控制方程与数学模型 → 数值离散格式 → 理论性质或机理分析 → 数值算例 → 结论与展望”的线性主线推进，避免多层嵌套小节与松散回顾。
2. **引言漏斗清晰**：用四步收拢至本文工作——物理或计算现象引发的困难、现有主要方法路线、既有路线在目标场景下的明确局限、本文方法的切入点与核心结果。
3. **正文与长证明分离**：避免在方法正文中间插入大段不分段的代数证明，拖垮主线可读性。核心卖点命题在正文简明陈述并给出短证明或证明思路，长篇技术引理与完整推导移至专门理论分析节或文末附录。
4. **中文排印与引用习惯**：
   - 交叉引用统一写清类别词，如“式 (1)”“第 2.3 节”“图 3”“表 2”，“式”字不省略；
   - 少用英文式的粗体导语圆点列表，优先改写为连贯段落或行内编号“（1）……；（2）……”；
   - 算法流程用编号公式序列或简洁步骤“步 1、步 2”给出，不堆砌伪代码框；
   - 摘要独立成篇，交代研究对象、关键方法与主要定量结论，不引用文献编号，不在摘要炫技堆砌未定义术语。

## 二、数值方法小节八条操作写法

将“定义—引理—定理”骨架转化为连贯可读的中文方法小节时，遵循以下八步：

1. **动机隔离**：方法节开篇只需一句范围声明加一句路线声明（先从简单情形切入再做系统推广，或先回顾常规格式再引出改进格式），随后立即进入网格、方程与记号。为什么这样做的动机留在引言或前一小节机理分析中完成。
2. **最小情境先行**：引出核心格式前，先用一两句构造最小具体对象（相邻两单元、孤立间断界面或单个时间步），让格式自然附着在具体几何与状态量上。
3. **记号随用随认领**：不单设孤立的“记号表”小节。新符号在首次出现的公式后紧跟一句话认领其物理或数学含义；临时速记（差分算子、省略上下标）在使用处就地说明“为记号方便”。
4. **公式缝在文字上**：每条展示公式前有引出句，后有“其中……”或定性解读句收尾，避免连续多条无文字衔接的公式堆叠。
5. **定理降密、注升密**：全文仅对 1 至 3 个核心结果使用定理或命题环境；其余辅助性质（守恒性、退化为单相、与旧格式的差异、边界实现细节）降格为编号“注”，每条注只讲一个性质并从具体式号出发。独立定义环境尽量化为“记 X 为 Y”的陈述句。
6. **性质紧随算法给出**：离散格式或算法步骤交代完后，固定补一组性质说明，每条性质同时给出所据式号与一句面向读者的物理或数值意义。
7. **预告、兑现与外部引用**：跨小节核心结论先预告、后兑现并指向对应算例图号；常规标准部件（经典限制器、时间积分方法）直接引用文献，不重复展开推导。
8. **推导段落五拍节奏**：典型推导段按“设定情境 → 关键演算 → 正确部分 → 然而（条件或缺陷）→ 定量与定性收尾”推进；每段首句回指上段已知信息，第二句切入新内容。

## 三、理论溯源与逻辑自洽红线

1. **正统文献支撑与零引用幻觉**：涉及理性力学、微分几何、守恒律或熵稳定等基础理论主张时，必须对照真实可读文献原件核实定理条件、作者与年份，禁止凭记忆编造引文或套用二手转述。
2. **禁止后文否定前文**：通读检查引言、方法、算例与结论四处是否前后一致。若某辅助机制在后续数值实验中表现出明显局限或失效区间，前文介绍时须如实界定其适用条件，不得前文将其写成主要支撑而结论反过来推翻前文。
3. **去内部研发痕迹**：正文彻底清除代码分支名、验收条目编号、测试通过项数及阶段返工措辞，使全文呈现为一次构思完成的严谨学术论文。
4. **结论与展望浑然天成**：结论只提炼经前文理论或数值实测证实的要点；展望应从本文已建立的框架自然延伸至下一步物理模型或高维推广，不突兀插入无关方向。

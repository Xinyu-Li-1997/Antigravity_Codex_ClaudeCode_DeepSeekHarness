# 通用学术语感与改稿自查清单

本文件用于**成稿之后的审改阶段**。初稿落笔时请先专注结构与论证，不要把本表当作写作紧箍咒，以免写出过度紧绷、句句设防的生硬文字。

## 一、自然学术语感六条基准

1. **一段只讲一件事**：首句给出本段核心判断或主题，后续句子给出推导依据、成立条件或例外情况，不留无逻辑承接的孤立短句。
2. **句子完整、主语明确**：用完整陈述句表达动作主体与因果关系，避免无主语电报体、连环定语嵌套与空洞动词包装。
3. **同义不复读**：同一事实在全文核心处讲清一次，后文通过节号、式号或表号回指，不在同一段换措辞反复强调。
4. **控制单句信息密度**：单句不宜塞入过多数值或多重分号串烧；待比较的数值较多时直接改用表格，每个数值配齐条件、单位与一致的有效位数。
5. **标题客观平实**：节标题使用名词短语准确概括本节对象，不用设问式或口号式标题。
6. **段落写完即止**：论证结束直接收束，不强加升华式感叹或空洞总结句。

## 二、改稿期重点排查的模板句式

| 常见生硬写法 | 改写方向 |
| --- | --- |
| “不是 A，而是 B” / “并非 A，而是 B” | 直接正面陈述 B；确需对比时拆为两句，先说 A 为何不成立，再陈述 B。 |
| 先虚设一个无人提出的错误说法再反驳 | 删去虚设靶子，直接切入真实问题与本文方案。 |
| “值得注意的是”“需要强调的是”“必须指出”“不妨”“让我们” | 直接删去提示语，保留实质判断。 |
| “由此可见”“不难看出”“综上所述”“归根结底” | 除全章总收束外一般删去，让结论自然立住。 |
| 破折号插入长段旁白 | 拆分为独立短句，或改用逗号从句与括号简短补注。 |
| 三段式修辞排比、情绪化程度副词（“极大地”“深刻地”“彻底攻克”） | 改为具体的定量幅度、误差阶数或适用范围。 |
| 对读者喊话（“你会看到”“请注意”）或自我表态 | 改为客观第三人称或标准学术第一人称叙述。 |
| 为自造非标准说法随意加引号 | 去掉引号，改用本学科通行术语或平实描述；引号仅留给直接引文、书刊名与标准原词。 |

## 三、行业外黑话与隐喻替换参考

对外学术论文、专著与科研汇报只使用本学科规范书面语，排查并替换常见业务黑话、战争隐喻与口语化工程简称：

| 需替换表达 | 推荐学术与工程书面语 |
| --- | --- |
| 口径 / 统一口径 | 定义、标准、统计方式、表述 |
| 落地 / 打通 / 贯通 / 拉通 | 实现、实施、衔接、贯连 |
| 闭环 / 抓手 / 赋能 / 沉淀 / 复盘 | 完整流程、切入点、支持、积累、事后分析 |
| 兜底 / 护栏 / 闸门 / 卡点 / 门测 | 保护性处理、边界约束、判据、瓶颈、回归测试 |
| 契约 / 承诺 / 担保（直译） | 约定、性质保证、成立条件 |
| 锚点 / 锚定 / 对齐 | 基准、观测支撑、一致、吻合 |
| 对账 / 台账 / 销账 / 挂账 | 核对、记录表、核销、暂记 |
| 遗产 / 服役 / 复活 | 旧版实现、现行版本、恢复启用 |
| 钉死 / 走死 / 掉阶 / 穿帮 / 坑 | 固定、失效、收敛阶退化、暴露缺陷、隐患 |
| 战场 / 命门 / 押注 / 反噬 / 雷区 / 武器库 | 适用场景、关键环节、取舍、副作用、风险区、可选方法 |
| 万灵药 / 金标 / 主菜 / 玩具算例 | 通用解法、基准标准、核心内容、简化测试算例 |
| 全绿 / 红线 | 全部通过、硬约束、不可违背条件 |

## 四、中英互译腔排查

1. **英文转中文**：拆解英文后置定语与被动长链，避免“提供了对……的支撑”“表现出……的能力”一类空动词直译；把直译词恢复为国内数值分析与力学教材的通行译名。
2. **中文转英文**：不要按中文词序逐句硬译，应按英文学术写作的自然主题推进重新组织句群；保持时态一致（已有方法与稳定数学性质用一般现在时，本文具体数值实验过程用一般过去时）。
3. **文献题名忠实**：引用中文原件时保留原题名，引用英文文献时保留原题名，不擅自二次意译。

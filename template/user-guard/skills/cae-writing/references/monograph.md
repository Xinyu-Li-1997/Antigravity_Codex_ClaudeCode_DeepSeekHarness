# 学术专著与长篇技术著作统一改写体例

适用于多章节学术专著、方法论综述与长篇技术书稿的整章写作或文风统一改写。

## 一、必须原样锁定的刚性内容

改写或统一多章文风时，以下内容逐字逐符号锁死，严禁在润色过程中改动、增删或重新编号：

1. **全部数学公式与变量记号**：上下标、算子符号、不等式方向与成立前提一概不变。
2. **全部数值与文献条目**：实验数值、收敛阶、量级以及每章参考文献的作者、年份、刊名与卷期页码保持原样。
3. **全部编号与交叉引用**：章号、节号、图号、表号、公式号与判据编号严禁错位。
4. **文档层级骨架**：各级标题层级、表格行列结构与参考文献区块保持一致。
5. **论点与限定边界**：不得增删实质主张、不得删去限定条件、不得引入原文没有的新断言或新文献。若改写核对时发现原稿存在确凿的公式笔误、数值抄错或引用错位，先单独登记并请作者确认，不在润色中静默改数；经确认后再于定稿阶段同步修正公式、数值与交叉引用。

## 二、整章逐句重写规范

1. **逐句重落笔而非局部换词**：不要仅用查找替换消去个别禁词，而应逐段按国内连续介质力学、计算物理与数值分析专著的语体重新组织语序、切分长句并理顺句间衔接。
2. **全书术语正名与唯一分工**：开工前先锁定全书核心术语表（例如误差、离散偏差、迭代偏差、理论收敛阶、观测收敛阶、目标量、网格收敛性研究、制造解法等各自精确分工），跨章节严禁同义混用或中英简称乱跳。
3. **标点与排版纪律**：
   - 尽量不用破折号插入旁白，优先拆成独立短句，或改用逗号从句与括号简短补注；
   - 禁用感叹号与连续省略号；
   - 去掉自造短语外层的装饰性引号，直接改写为清晰平实的学术短语；
   - 保持全书一致的中英文与数字混排空格习惯。
4. **平实克制、不抒情拔高**：陈述句为主，先给结论再给理由，或先给条件再给结论；每段讲清一层意思即止，不写段末抒情或展望式感叹。

## 三、分章交接与校验流程

1. 长书稿按章分批改写，每章开工前核对全书术语表与符号表，确保前后章风格无缝衔接。
2. 每章完成后执行两项校验：一是用确定性脚本核对公式、数字、编号与交叉引用零丢失，以及禁用句式与标点清零；二是安排干净上下文读者通读，核查有无搭配语病、断句歧义与翻译腔残留。

# 科研公文、阶段总结与结题报告体例

适用于向大同行评审专家、项目资助方、学术评估机构或合作单位提交的阶段总结、结题报告、年度汇报与研修总结。

## 一、读者画像与核心目标

此类报告的典型读者是**大同行评审专家或科研管理人员**，单份报告的快速扫读时间通常只有数分钟。行文目标是用清晰克制的书面语快速回答四个问题：

1. 研究面临什么核心科学或工程瓶颈；
2. 提出了什么解决思路与关键技术路径；
3. 取得了哪些经过验证的代表性成果；
4. 这些成果对学科发展或工程应用有何实际价值。

## 二、正负面写作边界

| 应当做到 | 严格避免 |
| --- | --- |
| 按主题归类成果，每项成果遵循“问题 → 做法 → 验证效果 → 价值”四拍推进 | 按日期记流水账，堆砌每周调试经过与返工过程 |
| 用定性规律配少量代表性量级指标说明改进幅度 | 堆砌内部测试组数、退出码、脚本文件名、具体行号或零散局部小数 |
| 删去密集数学推导与行内复杂符号，用准确物理概念讲清机理 | 把期刊论文的方法推导节原样搬进总结报告 |
| 客观界定既有领域共识与本人具体贡献，不贪前人之功、不自我夸饰 | 使用宏观连续介质里不成立的“微观机理”或“彻底攻克”“填补空白”等浮夸大词 |
| 严守事实边界，区分为已发表、已投稿、在研与后续计划 | 把尚在推进的计划写成已完成成果，或把内部讨论写成外部评审结论 |

## 三、双语报告与图表规范

1. **英文版独立重写**：中英双语报告的英文部分必须按英文学术总结的自然语序整篇重写，不可逐句机械直译中文长句。
2. **题名与专有名词忠实**：论文、报告与项目名称一律保留原件正式题名，不擅自将中文论文题名自行意译为不存在的英文标题。
3. **图表简洁双语自明**：双语阅读场景下的示意图与框图，图内标注须同步双语，保持留白均衡且无遮挡裁切；图片与表格承担浓缩信息的作用，正文直接提炼图表反映的核心结论。
4. **终审防“机械失明”**：完成格式与敏感词检查后，必须脱离源码与开发上下文以普通大同行身份从头通读一遍，重点排查长段压迫感、限定语套娃以及多期报告之间文风割裂的问题。
